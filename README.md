# BuilderHQ

Clash of Clans community hub for base layouts — browse, copy, feedback, and creator profiles.

Unofficial fan project. Not endorsed by Supercell.

## Docs
- `MVP.md` — current MVP execution plan (track progress here)
- `PROJECT.md` — full product vision
- `BRAND.md` — brand essentials

## Stack
- Next.js + TypeScript + Tailwind
- Supabase (auth + database)
- Cloudflare R2 (images)
- Vercel (hosting)

## Local setup
```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
